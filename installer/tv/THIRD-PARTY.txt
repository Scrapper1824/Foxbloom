Foxbloom TV Setup (FoxbloomTVSetup.exe) - third-party components
================================================================

sdb.exe (Smart Development Bridge)
  Copyright Samsung Electronics Co., Ltd.
  Part of the Tizen SDK tools. Licensed under the Apache License, Version 2.0 (full text in LICENSES.txt,
  shown under "Licences" in the installer):
  https://www.apache.org/licenses/LICENSE-2.0
  Embedded unmodified and run only to connect to a Samsung TV in Developer Mode, copy the Foxbloom app to it,
  install and start it. Source: https://github.com/Samsung/sdb (via the Tizen SDK).

Samsung CA certificates (SamsungCA.* resources)
  vd_tizen_dev_author_ca.cer and vd_tizen_dev_public2.crt are Samsung's public certificates (no private keys),
  shipped with Samsung's Certificate Extension for Tizen Studio. They are included so the app's signing
  certificate chain is complete; the installer checks each against a pinned thumbprint before using it.

adb.exe, AdbWinApi.dll, AdbWinUsbApi.dll (Android Debug Bridge)
  Copyright (c) 2006-2009, The Android Open Source Project
  Part of Google's Android SDK Platform-Tools (version 37.0.3). Licensed under the Apache License, Version 2.0
  (full text in LICENSES.txt): https://www.apache.org/licenses/LICENSE-2.0
  Embedded unmodified and run only to pair with and connect to an Android TV / Google TV that has Wireless
  debugging or Network debugging on, install the Foxbloom app on it and start it.
  Source: https://android.googlesource.com/platform/packages/modules/adb (the NOTICE.txt shipped with
  Platform-Tools lists the notices of everything it contains).

Foxbloom.apk (the Foxbloom Android TV app)
  Part of Foxbloom. It contains AndroidX WebKit and AndroidX Media3 (ExoPlayer), Copyright The Android Open Source
  Project, licensed under the Apache License, Version 2.0 (full text in LICENSES.txt).
  Source: https://github.com/androidx/media and https://android.googlesource.com/platform/frameworks/support
